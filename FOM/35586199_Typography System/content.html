📄 Page: Caption Rules

  • lowercase only

  • short phrases (2–6 words)

  • reflective, not instructive

  • end with period

Examples:

  • today, slowly.

  • sharing the same silence.

  • some moments are enough.

📄 Page: Placement Rules

Dark image → text higher
Open image → text lower

Opacity:

  • text ≈ 60–65%

  • logo slightly lower

Goal:
Text should feel discovered.
