What we have

Columns added to database

  • Follower count — raw scraped value

  • Posting frequency — derived from Notes/Month: High / Medium / Low / Inactive

  • Engagement level — derived from Engagement Rate: Very High / High / Medium / Low

  • Contact method — DM via Twitter/X if linked, otherwise http://note.com DM

  • Category — one of the four types above

  • Outreach Tier — Tier 1 / 2 / 3 (see segmentation below)

  • Outreach Status — Not Started / Contacted / Responded / No Response / Declined

Top 50 Selection Methodology

A Selection Score was calculated for each contact using four weighted signals:

Selection Score = Composite Score × 0.4 + Contact Score × 30 + (Followers / 50k) × 20 + Engagement Rate × 5

The top 50 were then selected with tier diversity enforced: 25 Tier 1, 20 Tier 2, 5 Tier 3 (adjustable). See the Top 50 Outreach List sheet in the attached Excel.
