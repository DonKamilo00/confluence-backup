Purpose

This page defines how MyndMap shows features without overwhelming users.

Feature marketing explains why, not just what.

Feature Announcement Standards

Each feature announcement must include:

  • Problem addressed

  • Who it’s for

  • What changed

  • How to use it

Visual Guidelines

  • Real screenshots

  • Real data (where safe)

  • No mock hype screens

In-App vs External

  • Major features → blog + app

  • Minor updates → in-app only

  • Iterations → quietly shipped

Golden Rule

If a feature needs hype to feel valuable,
it probably isn’t ready.
