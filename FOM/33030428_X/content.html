1. Thread Purpose

  • Insight / Feature / Reflection / Update

  • Why this belongs on X (short-form)

2. Hook (Tweet 1)

One calm, honest sentence.
No shock. No bait. No exaggeration.

3. Thread Structure

  • Tweet 2: Context

  • Tweet 3: Core insight

  • Tweet 4: Example or implication

  • Tweet 5: Reflection / takeaway

Optional:

  • Screenshot / visual (only if helpful)

4. Product Reference (Optional)

  • Mention only if genuinely relevant

  • No forced CTA

  • No pressure language

5. Quality Check

  • Would I say this in conversation?

  • No defensiveness or superiority

  • Adds clarity, not noise

Final Check

If this gets zero likes, was it still worth posting?
