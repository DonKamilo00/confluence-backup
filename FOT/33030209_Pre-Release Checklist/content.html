Purpose

This checklist ensures nothing important is missed before a release.

It must be completed for every App Store or Play Store submission.

General

  • Version number updated

  • Changelog written

  • No console errors

  • API keys secured

  • Feature flags verified

iOS Checklist

  • App launches cleanly

  • Permissions copy reviewed

  • No TestFlight warnings

  • Icons & splash screen correct

  • Crash-free dev build

Android Checklist

  • App launches cleanly

  • Battery usage acceptable

  • Permissions behavior correct

  • No Play Console warnings

  • Tested on multiple devices

UX & ND Checks

  • No cognitive overload introduced

  • Copy is calm and clear

  • Error states are humane

  • Notifications feel non-punitive

Final Sign-Off

  • iOS approved (Jordan)

  • Android approved (Kamil)

  • Release Owner approved

If any box is unchecked, the release does not proceed.

Closing Note

Checklists are kindness to your future self.
