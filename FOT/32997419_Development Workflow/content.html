Purpose of This Document

This page provides a high-level overview of how development flows at MyndMap — from idea → code → testing → release.

It exists to:

  • Prevent ad-hoc development

  • Reduce release risk

  • Keep iOS and Android aligned without coupling them

Core Principles

  • One shared codebase, two platforms

  • Expo-first, native-aware

  • Testing before confidence

  • Releases are deliberate, not rushed
