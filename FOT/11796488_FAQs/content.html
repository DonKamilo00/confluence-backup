1. General

What is MyndMap?

MyndMap is the world’s first natively built ADHD Operating System, designed to bring clarity, structure, and emotional stability into everyday life.

It includes:

  • Task management

  • Active Mode / Timer

  • Mood checking

  • Areas of Life

  • Grocery Lists with automatic priority sorting

  • Budgeting tools

  • MyndCooling

  • MyndBoard (public feedback board)

  • AI-powered reflections and goal breakdown

  • Organisation tools

  • Custom wallpapers

  • Non-dismissible reminders

  • Adaptive UX tailored for ADHD cognition

Everything is intentionally built to reduce overwhelm and support executive function.

Does MyndMap require an internet connection?

Yes. MyndMap is a cloud-connected OS built on Firestore.

An internet connection is required for:

  • Task creation, updates, and Active Mode sync

  • Kaizen Engine prioritisation

  • Mood Checker entries

  • Budget and spending updates

  • Grocery Lists

  • MyndCooling entries

  • AI Goal Decomposition (Premium)

  • Calendar Sync (Premium, in development)

  • MyndBoard submissions

  • Authentication and syncing across sessions

The OS cannot function offline.

Which platforms does MyndMap support?

  • iOS – Available now

  • Android (MyndOS Hikari) – Launching January 2026

Is MyndMap only for people with ADHD?

No.

While intentionally crafted around ADHD thinking patterns, MyndMap benefits anyone who experiences:

  • Overwhelm

  • Difficulty organising

  • Emotional overload

  • Procrastination

  • Poor planning

  • Busy schedules

  • Cognitive fatigue

3. Features

Tasks

How does the task system work?

MyndMap’s tasks are intentionally minimal to reduce cognitive overload.

Each task includes:

  • Title

  • Priority

  • Deadline

  • Reminder interval

  • Active Mode (timer)

  • OS notifications

There are no subtasks or microtasks.

This is deliberate — to prevent ADHD users from getting lost in nested structures.

Why does the timer reset when I close the app?

This is intentional.

It reinforces:

  • Task intentionality

  • Mindful starting and restarting

  • A “fresh moment” each time you open the app

  • Reduced attachment to “perfect time tracking” (which often derails ADHD users)

MyndMap prioritises action, not stopwatch perfection.

Kaizen Engine

What is the Kaizen Engine?

MyndMap’s internal OS algorithm that analyses:

  • Deadlines

  • Reminders

  • Priorities

  • Active Mode sessions

  • User behaviour patterns

It surfaces what matters most, reducing overwhelm and decision fatigue.

Areas of Life

What are Areas?

Areas are structured “rooms” of your life:

  • Work

  • Personal

  • School

  • Health

  • Projects

  • Home

  • And more

Within each Area you can create:

  • Lists

  • Notes

  • Plans

  • Structured documents

Premium unlocks unlimited Areas.

Grocery List

How does the Grocery List work?

Grocery items are automatically sorted by priority:

  • Essential

  • Important

  • Optional

This prevents overwhelm and helps users see what truly matters before shopping.

Budgeting

What does the Budget feature include?

The Budget screen includes:

  • Visual spending breakdown

  • Category totals

  • Remaining monthly budget

  • Spend caps

  • Day-by-day tracking

  • Helpful tips for ADHD budgeting

  • Categories: Food, Transport, Entertainment, Bills, Other (modifiable)

Mood Checker

What is Mood Checker?

A simple, refined emotional monitoring tool that tracks:

  • Mood

  • Stress

  • Work state

  • Relationships

  • Motivation

  • Energy

It helps identify patterns that affect productivity and emotional health.

MyndCooling

What is MyndCooling?

A grounding feature designed for emotional clarity.

Users can:

  • Write out emotional weight

  • Release intrusive thoughts

  • Journal frustrations

  • Calm down using built-in audio tracks

MyndBoard

What is MyndBoard?

A fully public, transparent feedback board inside the OS where users can submit:

  • Bugs

  • Feature requests

  • Translation issues

  • Aesthetic suggestions

  • UX improvements

  • OS Philosophy ideas

This creates a community-driven development cycle — rare in mental health apps.

5. Technical

The app is lagging or freezing — what should I do?

Try:

  • Updating the app

  • Restarting your device

  • Reinstalling MyndMap

  • Checking your internet connection

  • Disabling Low Power Mode

If the issue persists, email:

  • Device model

  • iOS/Android version

  • Issue description

  • Screenshots (optional)

Why am I not receiving reminders?

Check:

  • Notification permissions

  • Background activity

  • Battery optimisation settings

  • Active internet connection

MyndMap reminders sync via Firestore and require connectivity.

Does MyndMap work offline?
