2. What is KeePassXC?

KeePassXC is a secure, offline-first password manager built around a single principle:

Your security should never depend on a cloud service you don't control.

Features include:

  • AES-256 and ChaCha20 encryption

  • Encrypted local database (.kdbx)

  • Optional key file support

  • Built-in strong password generator

  • Auto-lock and inactivity lock

  • Browser integration for validated autofill

  • Cross-platform availability (Windows, macOS, Linux)

  • Fully open-source and audited

KeePassXC aligns with MyndMap’s internal philosophy:
Own your systems. Own your security. Own your outcomes.

3. Installation Instructions

3.1 Windows

  1. Visit: https://keepassxc.org/download

  2. Download the Windows Installer (.exe)

  3. Run the installer

  4. Approve prompts, keep defaults

  5. Launch KeePassXC

  6. Install the KeePassXC-Browser extension (Chrome/Firefox/Edge)

3.2 macOS

  1. Visit: https://keepassxc.org/download

  2. Download the macOS .dmg

  3. Drag KeePassXC into Applications

  4. Launch from Applications folder

  5. Approve the macOS security warning

  6. Install KeePassXC-Browser if needed

4. Creating Your Secure Database (.kdbx)

  1. Open KeePassXC

  2. Select Database → New Database

  3. Choose a clear name (e.g., “MyndMap_Credentials”)

  4. Use default encryption settings (AES-256 recommended)

  5. Create a strong master password (aim for 16+ chars)

  6. (Recommended) Add a key file stored separately from your .kdbx file

  7. Save the database in a secure, backed-up location

The goal is simple:
The master password is your only point of failure. Treat it as such.

5. Recommended Configuration

5.1 Auto-Lock

  • Lock when idle (5 mins)

  • Lock on system lock

  • Lock when minimized

5.2 Browser Integration

Enable via Tools → Settings → Browser Integration.

5.3 Password Generator

Use strong, random, 20+ character passwords for all entries.

5.4 Backup Strategy

Back up your .kdbx file weekly via your preferred secure method (OneDrive, encrypted drive, etc.)

6. What Must Be Stored in KeePassXC

Every credential related to MyndMap, development, operations, or internal tools must be stored securely.

This includes:

  • Server logins (SSH, RDP)

  • API keys

  • Database access credentials

  • Admin logins

  • Internal tools (e.g., Jira, Confluence, Slack)

  • Application secrets for development environments

  • Any credentials connected to production or infrastructure

Non-negotiable:

  • Do NOT store passwords in plaintext

  • Do NOT store credentials in browsers

  • Do NOT write passwords in notes, files, or messaging apps

Your security choices affect the entire team.
