Purpose

This document defines how releases are executed at MyndMap.

Releases are calm, deliberate events — not emergencies.

Release Types

Planned Release

  • New features

  • Improvements

  • UX updates

Hotfix

  • Bug fix

  • Regression resolution

  • Stability restoration

Release Flow

  1. Feature freeze

  2. Final testing

  3. Pre-release checklist

  4. Production build

  5. Store submission

  6. Monitoring

Platform Independence

  • iOS and Android may release independently

  • One platform never blocks the other unnecessarily

Rollout Strategy

  • iOS: App Store review → full release

  • Android: Optional staged rollout

Rollback Rules

  • Rollbacks are encouraged if needed

  • Ego never blocks rollback

  • Users always come first

Release Communication

  • Internal confirmation post-release

  • No public announcements unless meaningful

Closing Note

A good release feels uneventful.
