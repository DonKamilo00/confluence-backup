Purpose

This document defines the Android-specific development and release workflow, acknowledging platform differences.

1. Local Development

Tools

  • Expo CLI

  • Android Emulator / physical device

Used for feature work and logic changes.

2. Expo Go (Early Testing)

Used for:

  • Fast iteration

  • UI & logic validation

Not suitable for final QA.

3. Development Build (EAS)

Purpose

  • Push notifications

  • Background tasks

  • Android-specific behavior

Command

wide760

4. Android QA (Primary Owner: Kamil)

Checks

  • Device compatibility

  • Battery usage

  • Android version differences

  • Permissions behavior

  • Regression testing

5. Google Play Testing Tracks

  • Internal testing (fastest)

  • Closed testing (trusted testers)

Used to validate stability before production.

6. Production Release

Steps

  1. Increment versionCode & versionName

  2. Production AAB build

  3. Upload to Play Console

  4. Review warnings

  5. Rollout (staged if necessary)

Post-Release

  • Monitor Android-specific metrics

  • Compare iOS vs Android behavior

  • Report anomalies
