Purpose

This page defines how Firebase is integrated safely within a React Native (Expo) environment.

SDK Setup

  • Firebase initialized once

  • Environment-specific config

  • No re-initialization across renders

Config must be:

  • Explicit

  • Environment-aware

  • Version controlled

Async Safety

Rules:

  • Never assume immediate availability

  • Always handle loading states

  • Always handle errors

Firebase calls are async by default — code must reflect this.

Error Handling

  • All Firebase errors are caught

  • Errors are surfaced meaningfully

  • Silent failures are forbidden

Platform Differences

Be aware of:

  • iOS background behavior

  • Android lifecycle differences

  • Permission timing differences

Test both platforms explicitly.

Golden Rule

Firebase should never surprise the UI.
