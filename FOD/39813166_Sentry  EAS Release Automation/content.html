Purpose

Automatically connect every Expo build to a tracked Sentry release so crashes map to:

  • exact app version

  • exact commit

  • exact source code

This removes guesswork when debugging production issues.

Why This Matters

Without releases:

Crash occurred somewhere in the app.

With releases:

Crash occurred in v2.1.3, commit a83f21, Android 14 only.
