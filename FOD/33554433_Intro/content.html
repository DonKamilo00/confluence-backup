Expo Go is a development accelerator, not a production environment.
Its purpose is fast iteration, early validation, and visual testing — nothing more.

This documentation exists to:

  • Prevent misuse of Expo Go

  • Clarify where it fits in the dev lifecycle

  • Protect release quality

  • Maintain consistent workflows across contributors

What Expo Go Is

Expo Go is used for:

  • Rapid UI iteration

  • Logic validation

  • Early-stage testing

  • Template JavaScript builds

  • Cross-device sanity checks

What Expo Go Is Not

Expo Go is not used for:

  • Final QA

  • Native feature testing

  • Push notifications

  • Production validation

  • App Store / Play Store confidence

If native behavior matters, Expo Go stops.
