Purpose

This page defines how analytics are used intentionally, if enabled.

Analytics exist to inform decisions — not to collect noise.

Event Philosophy

  • Fewer events, higher signal

  • Clear naming

  • Consistent parameters

  • Platform-aware comparison

What to Track

  • Feature usage

  • Drop-off points

  • Platform divergence

  • Post-release changes

Never track:

  • Sensitive user data

  • Anything unnecessary

Usage Discipline

  • Events must justify existence

  • Events are reviewed periodically

  • Remove unused events

Golden Rule

If an event isn’t actionable,
it shouldn’t exist.
