Purpose

Define how MyndMap prioritizes fixes.

Not all crashes are equal.

Severity Levels

🔴 Critical (Fix Immediately)

  • App fails to launch

  • Navigation crash

  • Data loss

  • Login failure

Action:
Fix within 24 hours.

🟠 Major

  • Feature unusable

  • Repeated crash path

  • Payment or sync issue

Action:
Fix before next release.

🟡 Minor

  • Edge-case errors

  • Rare device failures

  • Recoverable UI bugs

Action:
Batch into scheduled updates.

⚪ Noise

  • Network retries

  • Cancelled promises

  • harmless warnings

Action:
Ignore or filter.

Founder Rule (Important)

Fix frequency > emotional reaction.

Top issue affecting 3% users matters more than rare dramatic crash.
