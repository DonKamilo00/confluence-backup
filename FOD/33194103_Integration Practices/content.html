Purpose

This page defines how MyndMap protects performance and reliability, especially as the app grows.

Performance regressions are treated as product bugs.

Re-render Control

Use:

  • React.memo for heavy components

  • Stable props

  • Minimal state lifting

Avoid:

  • Passing inline objects/functions

  • Unnecessary state duplication

Animation Best Practices

  • Prefer native driver where possible

  • Keep animations short and purposeful

  • Avoid blocking JS thread

Animations should reduce cognitive load — not add to it.

List Rendering

Rules for lists:

  • Always use FlatList

  • Stable keyExtractor

  • Windowing enabled

  • Pagination where appropriate

Rendering everything at once is forbidden.

AppState & Subscriptions

Every subscription must:

  • Be created intentionally

  • Be cleaned up reliably

  • Be scoped properly

Memory leaks are silent killers.

Firebase Read/Write Minimization

  • Batch writes where possible

  • Cache reads intelligently

  • Avoid polling

  • Observe usage costs

Every read has:

  • Latency cost

  • Monetary cost

  • Performance impact

Golden Rule

Performance issues compound quietly.
Fix them early.
