This page clarifies what kind of testing Expo Go supports.

Valid Testing

  • UI sanity checks

  • Navigation flows

  • State transitions

  • Copy accuracy

  • Visual regressions

Invalid Testing

  • Push notifications

  • Background tasks

  • Offline behavior

  • Performance benchmarking

  • Battery usage

Risk Awareness

Any confidence gained from Expo Go testing is:

  • Preliminary

  • Partial

  • Non-binding for release

Golden Rule

If a bug appears in production that Expo Go didn’t catch,
that is expected — not a failure of Expo Go.
