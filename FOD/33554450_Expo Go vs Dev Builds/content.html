This page helps decide which environment to use.

Use Expo Go When

  • Speed matters

  • Logic is non-native

  • You’re iterating visually

  • Risk is low

Use Development Builds When

  • Native features involved

  • Push notifications

  • Platform-specific behavior

  • QA & release confidence needed

Decision Shortcut

If you’d be uncomfortable shipping it after Expo Go alone →
use a development build.
