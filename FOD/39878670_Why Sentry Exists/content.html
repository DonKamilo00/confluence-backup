VS Code

VS Code shows errors only when:

✅ Code runs locally
✅ Developer reproduces bug
✅ Device connected
✅ Debugger active

Sentry

Sentry shows errors when:

✅ Real users experience crashes
✅ App runs on unknown devices
✅ Production-only bugs occur
✅ Async/network failures happen silently
✅ Native crashes occur outside JS
