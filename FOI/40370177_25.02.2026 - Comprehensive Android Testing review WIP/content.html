🔴 Critical Bugs (High Priority)

Focus: Core Loop & Background Logic

  1. Instant Timer Notification Misfire

  • Feature: Focus Timer / Task Execution

  • Issue: Starting a task (e.g., 60 minutes) triggers an immediate system notification stating: "Time is up have u completed the task?" This also occurs when pausing/resuming a task and minimizing/opening the app.

  • Technical Evidence (Logs): Console analysis shows scheduleTimerExpiration correctly calculates the delay (e.g., 300s for a 5-minute task), but Expo Notifications immediately dispatches it to the foreground ([AIGoalContext] 📬 Notification received in foreground).

  • Potential Root Cause: The trigger object configuration in Expo Notifications is likely misconfigured, causing immediate execution instead of delayed. Furthermore, logs show a brief duplicate state of the taskId being registered right before the misfire, which may be forcing the notification.

  • Impact: High. Breaks ND trust and creates immediate notification spam.

  1. Background Notification Failure (Persistent Issue)

  • Feature: Background Task Completion

  • Issue: When a task timer finishes while the app is minimized, no system push notification is delivered to the Android status bar.

  • Technical Evidence (Logs): Logs confirm the internal timer logic is working perfectly in the background. When returning to the app, logs show: V1.7.9: Updating 297 -> 231 (bg elapsed: 0 s) and Returned after 66 seconds. However, the OS-level notification trigger fails to fire while the app is out of focus.

🟡 UI, Usability & Localization Findings (Medium Priority)

Focus: Layout, Quality of Life, & Copy

  1. Keyboard Obstruction (Shopping List / Descriptions)

  • Feature: MyndBudget / Grocery List / Task Descriptions

  • Issue: When typing a number (quantity/price) or text description, the native Android keyboard physically covers the input field and the "Add Item" UI button.

  • User Friction: The user is typing "blind" and must manually dismiss the keyboard (pressing "Done" or the Android "Back" gesture) just to see what they typed or to press submit.

  • Recommendation: Wrap these specific screens in a KeyboardAvoidingView or adjust the padding dynamically so the input field scrolls above the keyboard.

  1. Missing Translation Keys (Discovered via Logs)

  • Feature: Timer Help Modal

  • Issue: The console is heavily spammed with missing translation warnings for the Timer Help component.

  • Log Evidence: WARN [i18n] Missing translation key: timerHelp.title, timerHelp.priorityGuide, timerHelp.description.

  • Impact: This indicates the en.json file is missing these keys, which will likely result in raw variable exposure to the user (similar to the previous premium.initializing bug).

Features tested thoroughly with no issues found.

  • Profile & Account: Navigation, saving details, and interactions work perfectly.

  • Notes: Creation, saving, and general functionality are stable. (The previous raw variable toast bug is resolved).

  • Budgeting Logic: The core math and logic for adding items and calculating budgets work correctly.
