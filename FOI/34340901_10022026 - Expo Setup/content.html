🚨 Incident Report: Android Build Pipeline Blocked
Date & Time: 2026-02-10 | 23:55 GMT
Owner: Kamil Maruszak
Status: 🔴 Active / Blocking

Incident Summary
The Android EAS build pipeline is currently non-functional due to missing cryptographic credentials in the current working branch. This prevents the generation of the Development Build (APK) required for Layer 2 (Native Features) and Layer 3 (Stability) testing.

Severity Classification
Level: P1 — High Reason:

Platform-specific blocking issue: Cannot generate Android builds.

Impact: Completely blocks testing of Push Notifications, Background Tasks, and Offline Mode for the upcoming Android release.

Platform(s) Affected:
Android (Build Infrastructure)

Root Cause
Branch Configuration Drift: The required Android configuration (eas.json updates and Android credentials) resides on a different Git branch than the current working branch.

Missing Keystore in Current Context: Because the active branch lacks the Android-specific merge, EAS defaults to iOS-only settings and attempts to generate a new Keystore, which would conflict with the Production app signature.

Resolution Steps
Immediate Action: Identify the branch containing the correct Android configuration (e.g., main or feat/android-setup).

Git Merge/Rebase: Merge the configuration branch into the current working branch to sync the credentials.json and eas.json files.

Build Execution: Run eas build --profile development --platform android once the correct credentials are present.


Preventative Actions
Branch Management: Enforce a policy to rebase feature branches against main (or the configuration source) before attempting release builds.

CI/CD Checks: Add a pre-build check to verify credentials.json contains platform-specific keys before allowing an EAS build command to run.
